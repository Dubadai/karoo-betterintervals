Workout done: icons on the tiles

Each tile gets the icon the workout screen uses, at the same size and place (top left, centred on the label): TIME the timer, AVG POWER and NP the bolt (Karoo green), AVG HR the heart (red; cadence's icon in green when Settings shows cadence). With a route the screen already fits: the check gets smaller and everything moves up. Drawn on the app's own done screens (field gallery).
