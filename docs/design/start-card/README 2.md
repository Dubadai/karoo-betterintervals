# Start card under the gear's tap area (2026-11-12)

The START box before a workout (indoors: PRESS START TO BEGIN with the Karoo picture; outdoors: START
WORKOUT) began 43 dp from the field's top, 21 dp inside the gear's 64 dp tap area, so a tap meant for
Settings could start the workout. The box now grows 24 dp into the big watts' room on a full page
instead of 46 dp (`INDOOR_BOX_EXTRA_DP`), so its top sits at about 65 dp, just under the gear's area.
On a shorter field (a route loaded) it was already smaller.
