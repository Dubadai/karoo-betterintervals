# Settings: Example card

Agreed 2026-11-07 (option A, `karoo-starter/docs/design/settings-preview/`): an "Example" card under
the title shows the workout screen as Appearance and Karoo style make it (ExampleScreen: interval
4 of 10 at 280 W, the showcase values), drawn by the real ScreenRenderer and shown 127 dp tall. It updates on every
tap and stays put while the settings scroll.

Screenshots (Karoo 3 emulator, debug demo data): `01-settings-example-karoo-light.png`,
`02-settings-example-classic-dark.png` (Karoo style Off), `03-settings-example-dark.png`.
