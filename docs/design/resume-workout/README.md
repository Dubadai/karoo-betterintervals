# Continue or start over (mock)

When a workout is removed and selected again during the same ride, and it was already under way
(saved progress for it today), the start screen asks instead of continuing silently:

- **▶ CONTINUE** (yellow, the Karoo's play colour): carries on where it left off ("INTERVAL 4 / 10 ·
  2:13 IN"). The Karoo's remote start button does the same.
- **START OVER** (tonal): from the first interval.
- The First up box and the chart point at the interval CONTINUE starts from.

Drawn over the gallery's start screen; not built yet.

Built (02-built-light/dark.png): the subline and START OVER as mocked; "START AT 4 / 10" and the chart point at the interval CONTINUE starts from. Picking another step with ⏮ / ⏭ turns it back into START WORKOUT. After an app restart mid-ride the workout still carries on by itself.
