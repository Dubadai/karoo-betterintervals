# Indoor start (approved 2026-11-11, built)

Indoors the Karoo's start / pause button runs the workout: the yellow START box shows a real Karoo 3
zoomed in on that button, which flashes green (once a second), with PRESS START TO BEGIN. Starting
the ride starts the workout (5 s countdown); a tap on the box starts the ride too. No pause button
indoors. A finished workout pauses the ride and hands the trainer back; between workouts mid-ride
ERG holds the When paused watts.

- `built/`: the app's own drawing (field gallery on the Karoo emulator)
