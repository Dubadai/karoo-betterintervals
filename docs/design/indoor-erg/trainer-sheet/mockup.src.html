Trainer sheet

A field can't see a swipe, so on an indoor ride with ERG the gear opens this sheet instead of Settings. It slides up over the ride, which keeps recording underneath; its top row stays visible. Swipe it down or press Back to return to the workout. "All settings" opens the usual Settings page.
